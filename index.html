CMC Workflow Help

Workflow

Review Droplet QC

Purpose: Reads files, extracts per-droplet traces, finds equilibrium plateaus, and assigns QC flags.

Cache: This is the expensive step. Changing log scale, fit model, sample type, or Used checkboxes does not reread files.

Plot / Fit CMC

Purpose: Aggregates Used droplets by file/concentration, draws σ vs concentration, and optionally fits a transition model.

Partial data: Files with no Used droplets are skipped with a warning; valid concentrations still plot.

Inputs

Files and Concentration

Add Files: Adds files in batches. FAMAS multi-experiment CSV, CSV, XLSX, and XLS are supported when runtime packages are available.

Concentration: The table value is used for plotting/fitting. Click the Concentration header to sort.

Sample Type

single: Labels the transition as CMC.

mixture / WSOM / unknown: Uses apparent CMC/CAC or transition concentration wording to avoid over-interpreting complex samples.

Optional Metadata

Temperature: Stored with the export for provenance; it is not forced into the model.

Density Override: Overrides source d(g/cm^3) when you need one density difference for the review.

Equilibrium and Plateau

manual window

Principle: Uses your Time Min/Time Max for every droplet.

Use when: You already know the stable region or want behavior close to the older time-window workflow.

auto plateau

Principle: Searches later windows, preferring low slope, low noise, sufficient points, and acceptable full-droplet evaporation.

Use when: Droplets equilibrate at slightly different times or files have many repeats.

Advanced Criteria

Min Plateau Window: Minimum window length used for σeq.

Max |Slope|: Drift limit in mN/m/min. Higher drift is flagged DRIFT.

Max Plateau SD: Noise limit within the selected plateau. Higher SD is flagged NOISE.

Max Full Evaporation Rate: Full-droplet volume loss per minute. High rate is flagged EVAP and excluded by default.

Aggregation Method: Mean is standard; median is more robust when accepted droplets are uneven.

Performance Preset

Fast: plateau stride 10000 ms, bootstrap 0, fit curve up to 150 points. Best for exploration.

Standard: plateau stride 5000 ms, bootstrap 100, fit curve up to 250 points. Default balance.

Full: plateau stride 1000 ms, bootstrap 300, fit curve up to 400 points. Use for final checks; slower on large batches.

Fit Models

none

Use when: You only want concentration-level σ points and droplet QC, or the series is too sparse for fitting.

surface tension CMC

Principle: Fits a pre-CMC decreasing line and a high-concentration plateau; CMC is their intersection.

Details: Positive concentrations enter log10(C) fitting. Very low baseline points may be excluded and recorded in diagnostics.

Default: Recommended for surface tension CMC/CAC work.

trend breakpoint

Principle: Finds a continuous segmented-regression breakpoint.

Caution: Useful as a trend diagnostic, but not recommended as the main σ-CMC model because it can find low-concentration onset.

flat plateau

Principle: Fits a left linear segment and a right constant plateau.

Use when: You want a stricter plateau assumption and have enough points on both sides.

QC Flags

Default excluded flags

NO_DATA: No usable σ values.

NO_PLATEAU: No valid equilibrium window.

DRIFT: Plateau slope exceeds the drift threshold.

NOISE: Plateau SD exceeds the noise threshold.

EVAP: Full-droplet evaporation loss/rate exceeds the threshold.

OUTLIER: Droplet is an outlier within its concentration group.

Warning-only flags

NO_VOLUME: No V(uL) data; σ can still be used, but evaporation QC is unavailable.

LOW_N: Few plateau points; inspect before trusting σeq.

Used checkbox

Meaning: Controls whether that droplet contributes to concentration-level aggregation.

Override: Manual changes are preserved in JSON export with provenance; flags remain visible.

Outputs

Plot and Export

Plot: Shows σ points, error bars, warning styling, fit segments, and CMC/CAC marker when available.

Export JSON: Includes review payload, plot payload, Used overrides, metadata, droplets, QC metrics, fit diagnostics, and options.

Publication Plot: Sends the current plot payload only; it does not recompute review or fit.
